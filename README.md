# TRS80_Model--1_plunger_fix
Repo for a basic repair to TRS80 model 1 keyboards.  This print slips over the neck of the keyboard plunger to keep the keys firmly in place.
Idea derived from https://deskthority.net/viewtopic.php?f=7&t=20317&start= 
I measured the plungers, used FreeCad to design and a Bambu Labs A1 to print.
